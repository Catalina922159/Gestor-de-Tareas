# Gestor de Tareas en Java 

Proyecto de consola desarrollado en **Java** para la gestión y seguimiento de tareas pendientes y completadas, aplicando conceptos de Programación Orientada a Objetos (POO).

---

## Características principales
* **Estructura Modular:** Uso de clases separadas (`Tarea` y `Main`) para mantener un código limpio y mantenible.
* **Colecciones:** Implementación de `ArrayList` para la manipulación dinámica de la lista de tareas.
* **Interfaz Interactiva por Consola:** Menú de opciones intuitivo con validaciones básicas de entrada mediante `Scanner`.
* **Control de Estado:** Permite registrar nuevas tareas, visualizarlas de forma ordenada y marcarlas como completadas.

---

## Tecnologías utilizadas
* **Lenguaje:** Java (JDK)
* **Paradigma:** Programación Orientada a Objetos (POO)
